# Library Catalogue - Node.js + MongoDB

Express app that stores books as documents in MongoDB Atlas (Mongoose).
nLive: https://mongo-library-demo.onrender.com

## Run
    npm install
    copy .env.example .env     # add your MONGODB_URI
    npm start                  # http://localhost:3000

## NoSQL features
- CRUD on documents with a nested object and an array
- Text search, filters, sorting, indexes
- Aggregation pipeline for the stats tables
